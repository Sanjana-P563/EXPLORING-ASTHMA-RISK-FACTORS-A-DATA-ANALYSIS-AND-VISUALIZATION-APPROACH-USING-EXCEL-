# EXPLORING-ASTHMA-RISK-FACTORS-A-DATA-ANALYSIS-AND-VISUALIZATION-APPROACH-USING-EXCEL-
# Worked with a large healthcare dataset (10,000+ records) in Microsoft Excel to explore how lifestyle, environmental, and medical factors influence asthma prevalence and control.
# Cleaned and prepared data by handling missing values, standardizing categories, removing unnecessary columns, and creating new fields using IFS, COUNTIF, and Excel formulas.
# Built PivotTables, Pivot Charts, and interactive dashboards to analyze trends in smoking status, air pollution, medication adherence, ER visits, and asthma control levels.
# Translated complex data into clear insights, highlighting how factors like smoking, medication adherence, and comorbidities impact asthma outcomes and healthcare decision-making.
